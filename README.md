# CoffeeOO Data Analysis

제주 로컬 카페 POS 데이터 기반 매출 분석 및 운영 전략 제안

## 1. Project Overview

제주 로컬 카페 CoffeeOO의 2022.02~2023.07 POS 거래 데이터를 분석하여 매출 및 고객 구매 특성을 파악하고 운영 전략을 제안한 프로젝트입니다.
운영시간, 메뉴별 매출 분석과 메뉴 연관성 분석을 수행했으며, 커피 소비 트렌드 리서치를 함께 활용하여 브랜드 경험 강화를 위한 운영 방향과 세트 메뉴 전략을 제안했습니다.

| 구분 | 내용 |
| --- | --- |
| 프로젝트 유형 | Team Project |
| 분석 데이터 | 카페 POS 거래 데이터 |
| 데이터 기간 | 2022.02.10 ~ 2023.07.30 |
| 데이터 규모 | 163,421 rows |
| 주요 분석 | 매출 분석, 메뉴 분석, 연관성 분석 |

## 2. Business Problem

CoffeeOO는 매출 감소 상황에서 매출 개선과 브랜드 경험 강화를 위한 구체적인 운영 방향이 필요한 상황이었습니다.

이에 다음 두 가지 질문을 중심으로 분석했습니다.

1. CoffeeOO의 매출과 메뉴 판매에는 어떤 특징이 있는가?
   → 브랜드 경험을 강화할 수 있는 운영 방향은 무엇인가?

2. 실제 주문에서 함께 구매되는 메뉴에는 어떤 패턴이 있는가?
   → 이를 활용하여 매출을 높일 수 있는 메뉴 구성을 제안할 수 있는가?

## 3. Dataset

- 기간: 2022.02.10 ~ 2023.07.30
- 데이터: CoffeeOO POS 거래 데이터
- 규모: 163,421 rows x 25 columns

주요 정보

- 결제 일시
- 상품명
- 상품 카테고리
- 판매 금액
- 주문 유형(매장/포장)

주요 전처리

- 결측치 및 이상치 처리
- 상품명 및 카테고리 표준화
- 날짜/시간 파생변수 생성
- 평일/주말 구분
- 계절 변수 생성

## 5. Key Findings

**① CoffeeOO만의 특색 있는 메뉴 수요**

시그니처, 핸드드립, 에스프레소 등 CoffeeOO의 특색 있는 메뉴가 음료 매출의 약 **67%**를 차지했습니다. 특히 핸드드립은 평균 판매기간이 약 **12일**로 메뉴 교체가 잦음에도 음료 매출에서 일정 수준 이상의 비중을 유지했습니다.

**② 매장 중심의 이용 형태**

포장보다 매장 이용 비중이 높게 나타나 CoffeeOO가 단순 테이크아웃 매장보다 **오프라인에서 커피를 경험하는 공간**으로 기능하고 있음을 확인했습니다.

**③ 메뉴 구매 조합**

연관성 분석에서는 음료-디저트 조합에서 **휘낭시에를 중심으로 한 조합**, 음료-음료에서는 **시그니처 메뉴 및 동일 메뉴의 서로 다른 원두 조합**이 확인되었습니다.
